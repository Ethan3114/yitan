# 阶段 3-1 验收

## 手机页面

真实语料入口：回忆录列表中的“李奶奶的故事”和“杨奶奶的故事”。两份内容于 2026-11-09 按当前撰写链路重新生成，每本 2 章；正文可展开段落原话，首页“访谈记录→查看原话”可阅读完整听悟转写。

电脑保持服务运行。手机连接同一 Wi-Fi，在浏览器打开 `http://192.168.120.123:3011`，填写已有邀请码进入。本机使用 `http://127.0.0.1:3011`。电脑 IP 变化时以项目状态的“已发出的信息”为准。

1. 打开已有回忆录，查看书封、篇数、访谈次数与目录；进入一章，正文应完整，展开“看看这段原话”应能看到对应出处。
2. 回到首页，打开“照片”，已有照片应正常显示；选择“添加老照片”，上传一张照片，完成后点击“从这张照片聊起”，访谈页应显示选中的照片。
3. 点击“我的”，进入老人资料；修改家乡并保存，再次进入应保留。返回回忆录，修改书名，刷新后书名应保留。
4. 进入访谈页，不勾选同意录音，点击“开始聊聊”应提示需要老人本人同意，麦克风不会启动。
5. 已完成的访谈可以整理成章节；执行时会显示整理进度，刷新页面可继续查看。已有章节重新整理需要确认，失败会保留原章节。
6. “家人”页提供共同阅读入口，并说明邀请功能的开放状态。独立邀请、阅读权限与留言在阶段 3-2 验收。

手机录音需可信 HTTPS。实体手机麦克风授权、外放回声与浏览器兼容性按阶段 3-3 验收；本阶段已通过真实历史录音重放检查语音链路。

# 照着做

网页现在开着：http://127.0.0.1:3011

1. 打开上面的地址。
2. 邀请码填 `yitan-local`，点「进入」。这是本机用的码，不要发到对话里。
3. 称呼填一位老人，点「保存」。刷新页面，这个名字还在。
4. 点进这位老人。不勾同意，点「开始通话」。页面会说先勾选同意，并且不会出现一通通话。
5. 勾上同意再点「开始通话」。现在会提示还没有豆包语音钥匙。这是对的，通话还没真正开始。
6. 钥匙要你自己去火山引擎豆包语音控制台复制，填进 `projects/忆谈/backend/.env` 的 `DOUBAO_API_KEY=` 后面，保存后告诉我。不要把钥匙贴到对话里。填好之后，再点「开始通话」，说一两句，应能听到回应，结束后能播放留下的录音。

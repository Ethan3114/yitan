# 阶段 3-2 阅读与家人功能

1. 同一 Wi-Fi 手机打开 `http://192.168.0.4:3011`，使用已有管理邀请码登录；电脑地址为 `http://127.0.0.1:3011`。电脑保持运行，局域网 IP 变化后需换成新的地址。
2. 进入李奶奶回忆录，点击底部“家人”，勾选要展示的章节及照片，点击“预览给家人看的内容”，检查后点击“确认展示这些内容”。
3. 在同页“邀请家人”生成邀请，复制地址给指定家人。原声默认不授权；需要分享时先确认整次访谈都适合展示，再分别勾选展示与邀请中的原声权限。
4. 家人连接同一 Wi-Fi，打开邀请，填写称呼进入独立阅读页面，读完可以选择章节留言。每份邀请仅供一人使用，七天有效。
5. 管理者在“家人”页查看成员和留言，可以撤销未使用邀请、移除成员、取消展示。对应权限立即失效；已经加载在对方页面上的内容无法远程抹除。
6. 章节阅读页可以补充核对说明；在“查看这次访谈的历史正文”读取旧版本，预览后确认恢复。恢复会更换该次访谈全部章节，并保存当前正文，不自动改变家人的展示版本。

后续写作和审查已经使用千问 Plus 思考模式。已展示的旧稿保留。

## 既有正文阅读

1. 在运行服务的电脑打开 `http://127.0.0.1:3011`，使用已有邀请码登录。
2. 在回忆录列表进入《李奶奶的故事·新版》，书籍编号为 `f919fddd-be5f-56ed-8681-b48d64af6e63`。
3. 进入目录中的各章阅读正文；展开“看看这段原话”，检查多处引用和原文位置。
4. 在核对事项中查看人物、时间和听写疑点；在访谈记录中查看完整原话。
5. 重点阅读第四章《金塔与酒泉：广播站里的青春与家庭》中物资不宽裕、医院生育及沙枣叶子之间的交代，以及迁居和工作变化。
6. 原有书籍仍保留，可分别打开阅读。新稿的事件数量、引用数量和模型检查结果见同目录的真实语料整改验证文件。

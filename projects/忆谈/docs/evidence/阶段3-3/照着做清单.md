# 手机验证

1. 手机与电脑连接同一 Wi-Fi。iPhone Safari 打开 `http://192.168.120.117:3080/yitan-ca.crt` 下载公开证书。已经安装并信任过的手机可沿用原根证书。
2. 设置 → 已下载描述文件 → 安装；设置 → 通用 → 关于本机 → 证书信任设置 → 开启本地证书完全信任。
3. Safari 打开 `https://192.168.120.117:3443`，应显示忆谈品牌首页且没有证书警告。点击“开始我的回忆录”体验引导，或点击“已有回忆录”使用已有邀请码。已有有效会话时恢复本人回忆录，`/welcome` 可直接查看产品介绍。
4. 进入自己的访谈档案。本人同意录音后开始，说一段真实经历；应听到 AI 回答。说话打断时，检查 AI 是否停止播放。
5. 结束访谈后，在“访谈记录”播放“双方对话录音”，检查老人和 AI 的先后顺序、停顿、重叠以及打断后的声音。展开“分别收听原始音轨”仍可查看两条原始录音。再次通话时切换后台，再返回，查看是否结束并保存。
6. 在浏览器中拒绝麦克风权限，检查提示是否说明如何允许，且话题仍保留。
7. 两台手机分别以管理者与家人进入，验证邀请、阅读、留言和撤销。Android Chrome 同样需要安装公开证书并验证实际通话。

新访谈使用同一时间轴的合成录音进行听悟转写；历史录音缺少时间信息时维持原状。iPhone 已确认 HTTPS 与实际通话，更新后的听感与外放回声仍需实际核验；Android 与双手机验证尚未完成。

## 本次手机前端

回忆卡可以展开问题，成书页可以展开版式说明，家人页说明章节与原声的授权范围。选择为自己或家人记录后，完成真实登录及建档；家属建档会显示交接页面。称呼是必填项，其他背景信息可展开填写。

20 个引导页面与 28 个原有页面通过 360、375、390、430px 检查，已验证登录、本人回忆录恢复、交接、录音同意保护。隔离数据库验证了家属和本人实际建档保存及刷新读取。检查未调用收费模型，阶段真实模型冒烟因早于本次代码更新记为待验。

# 阶段2-3技术开发文档｜第二次开场、同意和银行卡号

> 只做这三件，外加核对队列可以确认或拿掉。不改写章文风，不重录双人对话。

手册第二、三部分沿用阶段 2-2 的对账，无冲突。

## 一、阶段目标
- 第二次通话开场说出上次已经写成的那一章里的一句。
- 没勾同意就不建立通话，不留下录音。
- 原话里的银行卡号不写进章节，不记进记忆，文字稿里也不留这串数字。录音还在。
- 核对条目可以点「确认」或「这句不要」。

## 二、怎么做
- 开场摘要从上一章的标题和正文里截一段，不另叫模型。有摘要时，豆包开场先说这一句。
- 同意仍在建立通话之前检查。不同意只记一条审计，不建通话。
- 银行卡号用数字校验识别。对得上的数字从转写、章节和记忆里删掉，并在核对里留一句「没有写进正文」，不留卡号本身。

## 三、验收
- 已经有一章的老人，再点开始通话，开场会提起上一章。
- 不勾同意，点开始，页面说明还没同意，下面不出现新的通话。
- 文字里夹一条测试卡号，写成章节后正文和记忆里没有这串数字。
- 核对里点「这句不要」，状态变成已拿掉。重启后还在。

# 阶段 3-1 技术开发文档

## 1. 目标与范围

在手机上登录、建立老人档案、上传和查看照片、选择照片背景开始连续访谈、结束后整理成章，并通过书籍目录进入独立阅读页。刷新后从后端恢复整理状态与已有章节。

沿用已确认的前端适配声明。阶段 3-1 实现回忆录、我的、相册与访谈页面；家人导航提供本轮范围说明，邀请和留言按阶段 3-2 实施。书封使用原创排版与真实照片。界面以 390px 为基准，检查 360、375、390、430px。真实手机外放与完整异常恢复在阶段 3-3、3-2 验收，本阶段完成对应基础资源释放和持久化。

## 2. 实现

- 保留现有 Next.js 工程、SQLite 数据与接口；补充照片列表和授权读取、档案编辑、书名设置、章节详情、整理任务创建和查询。
- 产品经理于 2026-11-09 同意升级并完成回归：Next.js 16.4.5、React 19.3.1，路由参数使用异步接口，ESLint 使用独立命令，生产构建使用 Turbopack。最低浏览器为 Safari 16.4 或 Chrome 111。
- 新增独立表保存书籍设置、通话背景与创建幂等标识、整理任务；已有表结构与记录保留。书籍设置默认从档案称呼生成标题。
- 整理任务以数据库为事实来源，单通话唯一执行中的任务，持久化请求标识；后台执行任务，失败保留已有原文与章节，重启将中断的任务明确标为可重试失败。成功替换在单次数据库事务中完成。
- 照片使用 Pillow 验证真实图像，限制 10 MB 与像素数量。加密保存与读取延续现有方式，图片背景由用户填写后传入访谈指令。
- API 请求集中管理，Zod 校验关键响应；原生表单配关联标签、字段约束和提交状态。音频设备、播放资源与连接在结束或离开页面时释放。
- 自定义服务器统一代理网页、API、WebSocket，支持本地 HTTPS 证书配置；API 相对地址支持不同访问入口。证书和中间产物置于忽略目录。手机信任证书与真实设备录音按阶段 3-3 验收。

## 3. 页面与状态

| 页面 | 内容 |
| --- | --- |
| `/` | 品牌入口、邀请码登录、错误提示 |
| `/profiles` | 回忆录列表、建立档案 |
| `/profiles/[id]` | 原创书封、继续访谈、真实目录、照片、整理状态 |
| `/profiles/[id]/chapters/[chapterId]` | 正文阅读、原话展开、核对、原声、评分 |
| `/profiles/[id]/call` | 话题与照片背景、同意、麦克风权限、连续通话、结束 |
| `/profiles/[id]/family` | 本轮家人阅读范围说明，返回回忆录 |
| `/account` | 档案入口、相册与访谈记录入口、帮助隐私、退出 |

状态 `idle/submitting/queued/running/streaming/waiting_user/succeeded/partially_succeeded/failed/disconnected/stale` 按适配声明映射；取消整理为 N/A，页面离开不声称取消任务。各读取页面区分 loading、empty、permission_denied、not_found；缺少权限不展示业务数据。未知结果立即报错，不当作空内容。照片与章节不存在时使用有明确操作的空状态。

## 4. 接口契约

现有接口和统一错误结构沿用适配声明。新增接口前缀 `/api/v1`，所有访问校验家庭归属。

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| PATCH `/profiles/{id}` | 与 ProfileIn 相同字段 | 档案 ID |
| PUT `/profiles/{id}/book` | `title`，1–60 字 | `title` |
| GET `/profiles/{id}/photos` | 无 | `items`：ID、文件名、时间、授权图片地址 |
| GET `/photos/{id}` | 无 | 已验证的图片二进制 |
| GET `/chapters/{id}` | 无 | 章节、档案 ID、通话 ID与录音信息 |
| POST `/calls/{id}/draft-tasks` | `request_id`、`replace` | 持久化任务，返回 202；已有章节未确认覆盖返回 409 |
| GET `/draft-tasks/{id}` | 无 | `id/call_id/status/step/error_code/created_at/updated_at` |
| POST `/calls/{id}/abandon` | 无 | 结束未接通记录；已有声音保留 |

通话创建兼容扩展 `request_id`、`photo_id`、`topic`。重复请求返回原通话；照片必须属于同一档案。上传限制与错误遵循适配声明。普通读取超时 15 秒，任务查询每 2–10 秒，隐藏页面暂停；写入超时后通过原标识查询，用户重试不新增相同任务。

## 5. 验收与证据

- 启动真实服务，验证登录、档案、真实照片、已存在真实访谈内容、模型整理、阅读、刷新恢复、归属隔离和覆盖确认。
- 自动检查：类型、Lint、生产构建、后端测试、前端测试；不使用 mock 或虚构模型结果。真实模型验证脚本自动记录模型、用量、耗时与结构结果。
- 浏览器检查四种手机宽度、可访问名称、溢出、错误与网络请求；采集证据图片，不主动使用视觉识别。
- 新增任务必须验证重启恢复。原始数据和已有功能保留。模型失败如实记录，不能宣布通过。
- 证据位于 `docs/evidence/阶段3-1/`，`kit.sh 自检` 结果写入是否表。代表页面外观和实体手机效果仍需产品经理实际验收。

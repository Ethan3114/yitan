# 竞品参考与页面设计

参考来源：产品经理于 2026-11-09 在对话中提供的六张“小智回忆录”截图。下列判断仅依据截图中可见页面；邀请后的权限、留言实现和付费能力尚未经实际操作验证。

## 视觉方向

截图采用浅杏色顶部渐变、奶油白背景、深棕色文字、金色操作、白色大圆角卡片和固定底部导航。封面、人物插画、章节目录使内容具有一本书的形态；大字号与短文案把讲述、阅读和家人参与变成明确入口。

忆谈采用温暖、安静的家庭纪念册风格。页面以书封、真实照片、章节标题和讲述入口构成视觉重点。品牌名、封面、插画和文案使用忆谈自己的内容。

| 设计项 | 忆谈的规格 |
| --- | --- |
| 页面背景 | `#FBF7EF`；顶部从浅杏色 `#F7DAB5` 渐变到背景色 |
| 正文与标题 | 标题深棕 `#4B3430`，正文 `#302925`，辅助文字 `#75665D` |
| 主操作 | 深金棕 `#876020` 配白字；浅金 `#D5A45D` 用于装饰、选中背景与封面细节 |
| 卡片 | 白色、细暖色边框、24px 圆角、轻阴影；同页保持一致 |
| 字体 | 操作和说明使用系统中文无衬线；书名与章节标题可用系统宋体，正文提供清晰的阅读字号 |
| 字号 | 页面标题 28–32px，区块标题 22–24px，操作 20–24px，正文 18–20px，辅助说明至少 14px |
| 间距 | 手机页边 20px，卡片内边 20–24px，区块间 28–32px；8px 基础节奏 |
| 操作区域 | 主按钮高 64px，次按钮至少 48px；底部导航包含图标、文字与安全区域留白 |
| 图形 | 统一 Lucide 线性图标；书封使用可编辑标题、姓名与真实照片，默认使用原创排版封面 |
| 反馈 | 加载、空白、保存成功、失败、权限过期都有对应文案与操作，状态同时用文字表达 |

金色与白色的组合需实测对比度；正式功能文字遵守至少 4.5:1。全部页面以 390px 手机竖屏设计，检查 360、375、390、430px 宽度；采用单列内容与底部导航，章节阅读独立进入。封面有尺寸占位，底部导航适配安全区域，软键盘弹出时输入与提交按钮可见，浏览器工具栏变化不遮挡通话操作。正文放大到 200% 后仍能阅读与操作。老人、管理家属和受邀家人使用相同的手机设计体系。

## 回忆录

首页顶部显示当前书名与切换入口，中间展示书封、老人称呼、真实章节数量和最近更新。封面下是“继续聊聊”主按钮，以及根据上次访谈内容给出的简短话题。首次使用展示“开始第一次访谈”。

下方分为“目录”和“照片”。目录按已确认的人生顺序组织，章节展示标题、简短摘要、相关照片和阅读入口；时间不确定的内容明确标记待核对。照片提供浏览、添加与说明，照片里的人与事由老人确认。章节数使用实际统计，不以固定故事数量宣布整本书完成。

“从照片聊起”允许选择一张已有照片、填写人物与背景，再进入连续访谈；模型只使用已填写和口述确认的信息。章节阅读页具有书名、章节标题、正文、关联照片、原话与原声入口。管理者可核对、调整标题与章节顺序、选择给家人看的章节。首次读者直接进入阅读内容。

## 家人

“家人”页上方显示准备给家人看的书封与所选章节，下方显示成员、邀请状态和留言。空状态说明“选一段回忆，给家人看看”，主按钮为“选择章节”。

完整流程：管理者选章节 → 预览家人实际看到的内容 → 确认阅读范围 → 生成邀请 → 管理者自行交给家人 → 家人加入 → 阅读并留言 → 管理者查看留言和管理权限。

默认只开放选定的章节正文与明确选中的照片。录音需要单独勾选，原始逐字稿、禁忌话题、未确认事实和后台记录不随邀请开放。每位家人具有独立成员身份；成员只能访问对应书籍与获准内容。管理者可以撤销未使用邀请、移除成员、取消章节展示。失效入口说明原因并停止返回内容。

留言附着于具体章节，显示留言者和时间。家人可以删除自己的留言，管理者可以移除不适合的留言；留言与正文分开保存，内容变更须由管理者核对老人意见。章节修改后，家人继续看到已确认展示的版本，管理者预览后再更新展示版本。

产品经理已确认本轮同一 Wi-Fi 下邀请家人阅读与留言，后续上线支持异地。邀请页面提示设备连接同一 Wi-Fi、电脑保持运行。访问地址由部署配置生成，线上沿用成员与权限机制；上线后重新复制有效地址。

## 我的

展示当前身份、管理中的回忆录和账号操作。功能分组为“老人资料”“我的相册”“访谈记录”“使用帮助”“保存与隐私”。家人成员只看到获准使用的入口。

保存与隐私页面说明数据实际保存位置、哪些内容被发送给国内语音与写作服务、谁能阅读、如何撤销邀请以及录音同意规则。帮助内容覆盖麦克风权限、手机连接、整理失败和找回已有记录。

## 代表页面与验收

代表页面为回忆录首页、章节阅读页、家人页，分别展示已有真实内容、首次使用和未邀请家人的状态。视觉确认包括书封比例、标题层级、留白、导航、按钮和照片呈现。功能验收从真实访谈出稿到家人阅读完整操作，并覆盖邀请过期、权限撤销、其他家庭访问被拒绝和留言持久化。

阶段 3-2 使用同一 Wi-Fi 下两台设备验证邀请、阅读、留言与权限撤销。视觉和页面结构已于 2026-11-09 随阶段 3-0 验收通过。

# 忆谈 Figma 设计工具

用于更新现有文件 `ItHDGIIZGO2KLM24jMYr3Z` 中的第二版书式设计。工具依赖该文件已有页面、纸张和书封组件，不适用于空白 Figma 文件。页面与节点对应见 [设计说明](设计说明.md)。

构建前恢复本机 `data/showcase-books.json`，其格式与前端展示资料相同。然后在本目录执行：

```bash
npm ci
npm run build
```

在 Figma 桌面版中选择「插件 → 开发 → Import plugin from manifest…」，导入本目录的 `manifest.json`，在指定文件中运行「忆谈 · 书页交互设计」。它会更新“产品全流程”区域，并显示排版检查和六页连续翻页预览。运行前请保存当前设计；该区域由生成工具管理，运行会重建区域内的内容。

预览需保持 Figma 在前台，浏览器在后台会暂停动画帧。Figma Present 用于页面跳转；插件窗口用于连续卷页。

构建结果 `dist/code.js` 会包含展示语料，已经由仓库规则排除。不要上传或公开分享生成文件。源代码、依赖清单与设计说明不包含回忆录正文。
